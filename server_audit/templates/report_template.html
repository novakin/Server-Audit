Accounts & SSH keys

Docker containers

Environment file permissions

Metadata only. Environment permission checks do not read file contents or variable names. Optional Git secret scans read repository content separately.

$environment_table

Application environment sources

$application_table

Configured references/counts do not establish what a running process loaded. Docker env_file source paths are not retained by the daemon.

0600 is a common default; 0640 may be appropriate for an explicitly trusted service group. Review parent permissions and ACL findings before concluding access is restricted.

Git secret scanning

Local Git configuration and stored-object scans. Secret values and matching text are excluded from this report.

$git_table

Detections require review. If a credential is real, revoke or rotate it; removing a file does not revoke the credential. A scan with no detections is not proof of absence.

Scheduled tasks

Cron definitions and systemd timers. Pattern matches require local review; they are not malware verdicts.

$scheduled_table

Command bodies and script contents are withheld. Permissions, source files, timer history and coverage issues appear in collected evidence.

External verification

TCP observations from explicitly selected addresses. Location and independence are operator-supplied; results describe one source and time.

$external_table

Not observed does not mean protected. Same-port candidates do not prove service identity across NAT, proxies or CDNs. Untested addresses, UDP and omitted ports remain unknown.

Collected evidence

Full collected data, including failed checks. Values are shown as captured, without interpreting missing evidence as a pass.

$evidence
